# ⭐ Magic Star Puzzle

A polished, responsive Magic Star Number Puzzle built with plain HTML, CSS and JavaScript.

## Features
- Place numbers 1–12 exactly once
- Click-to-place and drag-and-drop
- Live line sums
- Check Solution, Reset, Hint and Show Solution
- Timer and move counter
- Green/red solution feedback
- Responsive design for desktop and mobile
- No Node.js, npm, framework or database required
- Works offline

## Run locally
Open `index.html` directly in Chrome, Edge, Firefox or Safari, or use VS Code Live Server.

## GitHub Pages
This is a static website, so it can be hosted with GitHub Pages. In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
